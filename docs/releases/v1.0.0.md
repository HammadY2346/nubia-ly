# nubia-ly 1.0.0

Personalize stock REDMAGIC with visual pickers, focused editors and saved styles.

## Included

- **Status bar:** clock appearance and dates, individual icon visibility, independent Wi-Fi/mobile styles, 16 coordinated Status bar + QS icon packs, and battery styles with percentage/charging controls.
- **Quick Settings:** portrait/landscape grids, large-tile arrangements, labels, brightness placement, tile shapes and slider treatments.
- **Lock screen:** clock fonts, fingerprint icons/animations and charging diagnostics.
- **Notifications, volume and power menu:** dedicated styling pages and controls around native firmware behavior.
- **Boot animations:** five choices supplied systemlessly by the guard after compatibility checks.
- **Saved enabled features:** resume in the background after first unlock, with independent stop and restoration controls.

## Requirements and installation

**REDMAGIC 11 Pro (NX809J), validated stock Android 16, root, Vector and a compatible Zygisk environment.** Other models and ROMs are not supported yet. Boot-animation support additionally checks the KernelSU setup and exact firmware player.

1. Install `nubia-ly-v1.0.0.apk`.
2. Install `nubia-ly-guard-v0.1.15.zip` through your root manager.
3. Enable nubia-ly in Vector with System UI and Fingerprint SensorService selected, then reboot.
4. Open the app, grant root, check Setup & device, choose styles and press **Enable customization**.

Existing official signed test installations can update in place. The guard is unchanged at 0.1.15; users already on that version do not need to reinstall it. Reboot after updating the APK.

[Full installation, updating and recovery guide](https://github.com/austineyoung2000/nubia-ly/blob/main/docs/INSTALLATION.md).

GitHub's automatically generated source-code ZIP/TAR files are not APKs or root modules.

## Scope and recovery

Firmware retains control of tile actions, volume, authentication and power actions. Unsupported icons and warning states remain native; pack coverage varies. Stock APKs are not replaced. Boot artwork uses a verified file bind while the original archive remains intact.

Use Restore stock appearance, Emergency stop or the guard's root-manager Action to revoke customization. Boot-animation restoration takes effect after reboot. The guard does not promise recovery from every possible boot failure.
